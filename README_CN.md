## 🎯 三大运行模式

<table>
<tr>
<td width="33%">

### 🔬 微观模式（Micro）
**审查**单个页面、卡片、按钮或交互。

输出：**三层方案**（稳妥 / 均衡 / 前卫），附带精确的像素值、弹簧参数、WCAG 对比度。

```
"审查这个页面的设计质量"
"这个卡片的间距和阴影合理吗？"
```

</td>
<td width="33%">

### 🏗️ 宏观模式（Macro）
**从零架构**一个完整的品牌体验。

输出：**4 幕品牌蓝图** — 从裂变分享时刻倒推到日常 UI → 入门引导 → 营销物料。

```
"帮我从零设计健身 App 的品牌体验"
"倒推品牌设计 — 用户会炫耀什么？"
```

</td>
<td width="34%">

### 🧬 取证模式（Forensic）<sup>新</sup>
用**第一性原理物理学公式**反推任何设计的好坏根源。

输出：**9 维取证报告**，含公式评分、诊断、可落地修复方案。

```
"这个设计为什么好看？用公式反推"
"分析这个截图的设计原理"
```

<details>
<summary><b>展开原则详情</b></summary>

| # | 名称 | 描述 |
|---|------|------|
| 1 | 80/20 平台法则 | 80% Apple HIG + Material 3 基础，20% 品牌灵魂 |
| 2 | 可选最优 | 永远提供 3 个方案：稳妥 → 均衡 → 前卫 |
| 3 | 设计即物理 | 动效遵循弹簧动力学，禁止线性运动 |
| 4 | 全局一致性 | 每一个像素都尊重品牌视觉 DNA |
| 5 | 技术栈无关 | 先做设计决策，再适配框架 |
| 6 | 1px 工匠精神 | 发丝边框、分层阴影、克制的玻璃拟态 |
| 7 | 80/20 色彩法则 | 80% 中性色，20% 有"数据工作证"的意图色 |
| 8 | 留白即奢侈 | 慷慨的留白 = 高级感。拥挤 = 廉价感 |
| 9 | 字号极端双标 | 极端对比：巨型锚定数字 + 低语标签 |
| 10 | 双轨资产 | 功能图标 ≠ 表现力插画，绝不混用 |
| 11 | 便当盒排版 | 所有内容装进圆角容器，不散养在背景上 |
| 12 | 多色抉择过滤 | 5 关过滤：有分类？同滤镜？预算内？一姐规则？模糊规则？|
| 13 | 米其林大厨法则 | 产品逻辑 → 去腥（消摩擦）→ 增香（注多巴胺）→ 增彩（奢侈包装）|
| 14 | 感官微反馈 | 每次触摸 → 100ms 内产生视觉 + 触感反馈 |
| 15 | 社交货币制造 | 在情绪巅峰制造可分享的"炫耀海报" |
| 16 | 4幕品牌闭环 | 场外放毒 → 走红毯 → 过日子 → 炫耀反哺 → ♻️ |
| 17 | 60-30-10 色彩法 | 60% 基调色，30% 辅助色，10% 焦点色。均分 = 混乱 |
| 18 | HSB 光影物理 | 暗态：S↑ B↓。亮态：S↓ B↑。禁止随意改 H |
| 19 | WCAG 信息清晰度 | 文本 ≥ 4.5:1 对比度。装饰元素 ≤ 1.5:1 主动退让 |
| 20 | 数学比例秩序 | 8pt 网格，乘数音阶（1.25–1.618），φ/√2 比例 |
| 21 | 格式塔最低认知 | 亲密性 3:1，相似性 ≤5 种变体，闭合用留白代替线条 |
| 22 | 排版灰度密度 | 眯眼测试 = 均匀灰度，无黑块无白洞 |
| 23 | 容器微质感 | 1px 边框 + 噪点肌理 + 方向性内发光 |
| 24 | 数据艺术与纵深 | 去坐标轴、极粗霓虹曲线、Z 轴遮挡纵深 |

## 🧬 9 维取证扫描 <sup>v4.0 新增</sup>

在**取证模式**中，提供一张截图或一段代码，技能将运行基于物理学的 9 维审计：

```
维度             公式来源                   核心问题
──────────       ──────────────────────     ─────────────────────────
1. 色彩分配       60-30-10 空间比例          颜色预算是否平衡？
2. 色彩物理       HSB + WCAG                状态变体是否符合物理学？
3. 数学秩序       8pt 网格 + 乘数音阶        每个尺寸是否有数学依据？
4. 格式塔         亲密性 · 相似性            大脑解析是否零负担？
5. 排版韵律       Tracking · 眯眼测试        黑白灰是否有节奏流动？
6. 运动质量       弹簧 · 错层 · <100ms       交互是否有生命感？
7. 容器质感       边框 · 噪点 · 内光          表面是否像真实材?
8. 数据可视化     去坐标轴 · 极粗曲线         图表是艺术品还是表格？
9. 纵深构图       Z 轴分层 · 遮挡             是否有三维纵深感？
```

每个维度打分：✅ 通过 · ⚠️ 部分 · ❌ 不通过 · ➖ 不适用

## 🍳 米其林大厨框架

> *没有 UX/UI 护航的产品逻辑，就是一块带血的生肉 — 有营养但咽不下去。*

```
    🔪 去腥               🥩 增香              ✨ 增彩
    消灭摩擦              注入多巴胺            奢侈品包装
    ─────────            ─────────            ─────────
    • 切片喂饭法           • 弹跳缩放 +          • 光环效应
      (渐进式披露)          触感反馈on tap       (颜值 = 信任)
    • 后悔药安全网         • 游戏化指标           • 可分享的
      (撤销 toast)         (🔥连续打卡, XP)       炫耀海报
    • 智能默认值           • 庆典仪式             • 裂变闭环
    • 温柔报错               (3D勋章+金币雨)       在此完成
```

## 🎬 4 幕品牌体验闭环

用于**宏观模式** — 将整个用户旅程设计为自我强化的无限循环：

```
  ┌─ 第1幕：场外放毒 ──── "我们在兜售什么'理想人设'？" ─────────┐
  │  App Store 3D 样机 · 人设视频 · 品牌人格宣言                   │
  └──────────────────────────┬──────────────────────────────────┘
                             ↓
  ┌─ 第2幕：走红毯 ──── "打开 App 的前 3 秒有没有接住人设？" ────┐
  │  动效衔接桥 · 品牌化权限请求 · 新手引导流                      │
  └──────────────────────────┬──────────────────────────────────┘
                             ↓
  ┌─ 第3幕：过日子 ──── "日常使用有没有破坏这个人设？" ──────────┐
  │  品牌语调 · 品牌化报错 · 触感语言地图                          │
  └──────────────────────────┬──────────────────────────────────┘
                             ↓
  ┌─ 第4幕：炫耀反哺 ──── "分享时刻有没有美到忍不住发圈？" ──────┐
  │  炫耀海报 · 庆典仪式 · 社交分享基础设施                        │
  └──────────────────────────┬──────────────────────────────────┘
                             └──── ♻️ 用户分享 → 新用户发现 → 回到第1幕
```
